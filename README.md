# rent-flow-grok

Design canvas for **RentFlow** — a Bangla-first, mobile-first property and rent management web app.

These are visual design deliverables (HTML/CSS). There is no backend or app logic.

## View

Open [design-output/index.html](design-output/index.html) in a browser.

## Package

- `design-output/` — screens, components, assets
- `design-system/` — tokens
- `handoff/` — developer handoff
- `Logo/` — brand marks and guidelines
